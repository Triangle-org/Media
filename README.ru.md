# Triangle Media

Triangle Media — плагин для изображений в приложениях на Triangle Engine. Он принимает загружаемые файлы и ссылки на изображения, проверяет и преобразует допустимые файлы в PNG, сохраняет метаданные через подключение к базе данных приложения и может отдавать изображения с изменениями размера и другими фильтрами.

## Совместимость

- PHP 8.1 или новее
- Triangle Engine 9
- Расширения PHP: `curl`, `fileinfo` и `imagick`
- Доступный для записи каталог изображений и настроенная в приложении база данных

Последний опубликованный тег пакета — `v1.1.0`, он требует Triangle Engine `^8.1`. Эта ветка подготавливает следующую основную версию для Triangle Engine 9 и Server 7; миграция ещё не опубликована как стабильный релиз. Следующая основная версия не будет совместима с Engine 8.

## Установка

Для опубликованной версии с Engine 8:

```sh
composer require triangle/media:^1.1
```

После публикации совместимого с Engine 9 релиза `2.0.0` устанавливайте его командой `composer require triangle/media:^2.0`.

Triangle Engine обнаруживает контроллеры плагина через Composer autoload. Метод `Triangle\Media\Install::install()` копирует отсутствующие настройки по умолчанию из `src/Config` в `config/plugin/triangle/media`, сохраняя уже существующие настройки приложения. При установке пакета его должен вызвать механизм установки плагинов приложения.

В пакете нет шаблонов представлений. Чтобы использовать встроенные маршруты с представлениями, установите `triangle/view` и добавьте в приложение шаблоны `index`, `form` и `image`. Вместо этого приложение может заменить контроллеры собственным слоем представления.

## Пути контроллеров по умолчанию

При стандартной настройке Triangle Engine `app.plugin_uri` контроллеры доступны по следующим путям:

| Путь | Метод | Назначение |
| --- | --- | --- |
| `/app/media` | `GET` | Отображает `index`; устанавливает cookie `token`, если запрос содержит токен. |
| `/app/media/project` | `GET`, `POST` | Возвращает `403`, пока регистрация проектов выключена. Если она включена, `GET` отображает `form`, а `POST` проверяет поля, сохраняет проект и возвращает его токен. |
| `/app/media/upload` | `POST` | Принимает загруженный файл или ссылку после проверки токена проекта. |
| `/app/media/image/{image-id}` | `GET` | Отображает `image` для существующего изображения. |
| `/app/media/processing/{image-id}/{filters...}` | `GET` | Применяет заданные фильтры и возвращает байты изображения. |

Префикс меняется, если приложение переопределяет `app.plugin_uri`. Настройте маршрутизацию, контроль доступа и ограничения частоты запросов на уровне приложения или обратного прокси в соответствии с условиями эксплуатации.

## Настройки

Параметры по умолчанию устанавливаются в `config/plugin/triangle/media/app.php`:

| Параметр | Значение по умолчанию | Назначение |
| --- | --- | --- |
| `enable` | `true` | Включает конфигурацию плагина. |
| `project_registration` | `false` | Разрешает регистрацию проектов через контроллер, если настройка включена. |
| `image_uri` | `https://example.ru/media/` | Публичный базовый адрес изображений; замените его на адрес вашего сервиса. |
| `image_path` | `public_path() . '/media/upload/'` | Каталог для преобразованных изображений; приложение должно разрешать запись. |
| `max_file_size` | 15 МиБ | Максимальный размер исходного файла. |
| `max_image_pixels` | 40 000 000 | Максимальное суммарное число пикселей во всех кадрах. |
| `max_image_frames` | 50 | Максимальное число кадров во входном изображении. |
| `max_image_memory` | 256 МиБ | Лимит памяти ImageMagick и его map-ресурса. |
| `max_image_disk` | 512 МиБ | Лимит дискового ресурса ImageMagick. |
| `max_image_time` | 10 секунд | Ограничение времени обработки ImageMagick. |
| `rate_limiter.enable` | `false` | Включает настроенный ограничитель частоты запросов. |
| `rate_limiter.quota` / `cycle` | `3` / `60` | Допустимое число запросов за период при включённом ограничителе. |

В этом файле также настраиваются допустимые MIME-типы, формат PNG, имена таблиц/коллекций и шаблоны преобразований. Считайте настройки частью политики приложения: перед открытием загрузки проверьте публичный URL, права каталога и ограничения ресурсов.

Установка сохраняет существующую конфигурацию приложения. После обновления старой установки отдельно проверьте `project_registration` и установите `false`, если анонимная регистрация проектов не нужна.

Приложение должно предоставить совместимые адаптеры `db()` и `storage()`. Адаптер базы данных должен поддерживать `insert($table, $record)` и `where($field, $value)->getOne($table)`. Адаптер хранения должен поддерживать `get($key)`, `set($key, $value, $ttl)` и `increment($key)`. Triangle Engine предоставляет `config()`, разрешение IP запроса и функции ответа. Функцию `view()` предоставляет `triangle/view`; шаблоны `index`, `form` и `image` добавляет приложение. Пакет не включает адаптеры базы данных или хранения.

## Загрузка изображений

Контроллер загрузки принимает multipart-файл в поле `file` или ссылку в поле `link`. В обоих случаях проверяются MIME-тип и размер. Загрузчик преобразует изображение в PNG, сохраняет запись через помощник базы данных Engine и возвращает идентификатор, URL, MIME-тип, размеры, основной цвет и размер результата.

Для загрузки по ссылке разрешены HTTP и HTTPS на стандартных портах. Плагин запрещает URL с учётными данными и адреса из непубличных диапазонов, закрепляет проверенный DNS-адрес на время запроса, не переходит по редиректам и ограничивает объём данных и время загрузки. Эти меры уменьшают риск SSRF, но не заменяют сетевые ограничения исходящих подключений на уровне хоста.

Контроллер обработки поддерживает настроенные фильтры `crop`, `resize`, `pixelize` и `cover`. Результаты кэшируются через сервис хранения приложения.

## Проверки разработки

```sh
composer validate --strict --no-check-publish --no-interaction
composer run check --no-interaction
composer audit --locked --no-interaction
```

Тест безопасности URL отклоняет локальные, зарезервированные и нестандартные адреса. Декодирование и преобразование изображений требуют расширения `imagick`; локальный тест не заменяет интеграционную проверку загрузки с базой данных, маршрутизатором, кэшем и шаблонами приложения.
